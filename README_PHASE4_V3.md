# Phase 4 v3 — 表記ゆれ対応

## 公演名の省略

会場名がなくても、都道府県と開催日数があれば特定できます。

```text
@大阪 2日目
```

対応する日数表記：

- Day2
- DAY 2
- 2日目
- 2日め
- 二日目

一方、`@大阪` だけで大阪に複数開催日がある場合は、
誤反映防止のため公演を特定しません。

## ツアー名の誤記・省略

公式名の正規化一致に失敗した場合のみ、
安全条件付きの類似度判定を行います。

例：

```text
ICEx Forth Tour 2026 'FRESH'
```

も対象ツアーとして認識できます。

安全条件：

- ICEx表記が残っている
- 両方に年がある場合は年が一致
- 類似度が閾値以上
- 複数登録ツアーが同程度に近い場合は自動判定しない
