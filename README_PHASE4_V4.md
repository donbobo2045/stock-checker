# Phase 4 v4 — 公演特定を安全側へ修正

## 地域情報を必須化

公演を特定する際、最低でも以下のどちらかが投稿本文に必要です。

- 正式会場名
- `東京` / `大阪` / `愛知` / `福岡` など `events.csv` の開催地域

そのため、

```text
@2日目
```

だけでは公演を特定せず、自動反映しません。

## 同一地域に複数開催日がある場合

例えば大阪にDay1 / Day2がある場合、

```text
@大阪
```

だけでは自動判定しません。

以下のように日を絞れる情報が必要です。

```text
@大阪 Day2
@大阪 2日目
9/19 大阪
```

## 1開催日の地域

その地域で物販セッションが1日しかない場合は、

```text
@東京
```

のように地域名だけでも特定できます。

## 安全性

解析優先順：

1. 対象ツアー
2. 地域 / 会場
3. 明示日付
4. Day1 / Day2 / 1日目 / 2日目
5. 商品・variant

複数の公演候補が残る場合は自動反映しません。
