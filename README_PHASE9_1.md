# Phase 9.1 — 初期表示を直近公演へ

アプリを開いたときの公演選択を、
CSVの先頭固定ではなく日付から自動判定するようにしました。

## ルール

現在日を基準に、

```text
今日以降で最も近い公演日
```

を初期表示します。

例：

```text
現在日: 2026-09-22
→ 東京 2026-09-23
```

同日に1部/2部がある場合は、
その日の最初の公演を初期選択します。

在庫は同日の `sales_session_id` を共有しているため、
商品在庫表示上は同じ物販セッションです。

## 当日の扱い

時刻ではなく「公演日」を基準にするため、
その日の終演後でも日付が変わるまでは当日公演を初期表示します。

## 全公演終了後

今日以降の公演が存在しない場合は、
最終公演日にフォールバックします。

これによりアプリが空表示にはなりません。

## 複数ツアーへの備え

将来複数ツアーが `events.csv` に入った場合は、
全イベント中の直近公演から初期ツアーも選択します。
