# Phase 4 v2 変更点

完売投稿の判定を以下のように変更しました。

1. 対象ツアーかを判定
2. `本日分完売` が含まれるか判定
3. 公演を特定
4. 商品・variantを特定

`【完売情報】` は任意の見出しとして扱います。

そのため、以下のような投稿も解析できます。

```text
#ICEx
『ICEx Fourth Concert Tour 2026 ''FRESHest!!''』
@大阪・NHK大阪ホール Day1

・アクリルスタンド（阿久根）
・アクリルスタンド（八神）

本日分完売です！
ありがとうございます。
```

また、別ツアーの投稿は「対象ツアーを特定できない」として先に除外されます。
