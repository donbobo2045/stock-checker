# Phase 8 — Streamlit上の開発者用テスト設定

## 目的

`config.py` を毎回編集してStreamlitを再起動する必要をなくしました。

サイドバーの

```text
🧪 開発者用テスト設定
```

から、以下を直接変更できます。

- 販売終了ステータス ON / OFF
- 仮想現在時刻 ON / OFF
- 仮想日付
- 仮想時刻

Streamlitのウィジェット変更時に自動rerunされるため、
設定は即時反映されます。

## config.py

`config.py` は今後「初期値」だけを持ちます。

```python
ENABLE_SALES_END_STATUS = False
TEST_NOW_ISO = None
```

テスト段階ではこのままでOKです。

## 推奨テスト

### 通常テスト

```text
販売終了ステータス: OFF
仮想現在時刻: OFF
```

### 東京公演・販売前

```text
販売終了ステータス: OFF
仮想現在時刻: ON
2026-09-23 12:00
```

期待:

```text
🟡 販売前
```

### 東京公演・販売中

```text
販売終了ステータス: OFF
仮想現在時刻: ON
2026-09-23 14:00
```

期待:

```text
🟢 販売中
```

### 東京公演・販売終了

```text
販売終了ステータス: ON
仮想現在時刻: ON
2026-09-24 00:01
```

期待:

```text
🔴 完売済み商品 → 完売
⚫ その他の商品 → 販売終了
```

## CSV/parser再読込ボタン

既存の

```text
CSV / alias / parserを再読み込み
```

ボタンは残しています。

これはCSVやalias/parserのキャッシュをクリアするためのもので、
開発者用テスト設定の反映には不要です。
