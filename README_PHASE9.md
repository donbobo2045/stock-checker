# Phase 9 — スマホ/タブレット最適化 + グッズ検索

## スマホ表示

Streamlit自体にはレスポンシブ機能がありますが、
従来画面はPC向けの横並びが多かったため、以下を変更しました。

- 画面幅を約980pxに制限
- スマホ時の左右余白を縮小
- タップ対象を44px以上に調整
- スマホでズームが起きにくい入力文字サイズ
- 5列の公演情報を横並びからテキスト表示へ変更
- 4列の在庫サマリーを1行表示へ変更
- 商品カードの画像/情報を縦積みに変更
- variantの3列表示を縦積みに変更
- 手動完売ポスト解析を折りたたみ表示に変更
- スマホでの公演変更は左上メニューからサイドバーを開く案内を追加

## グッズ検索

在庫一覧の直前に検索欄を追加しました。

検索対象：

- 商品名
- メンバー名 / variant
- item_id
- item_aliases.csv に登録された略称

例：

```text
うちわ
山本
アクスタ
ペンラ
シール
```

`シール` や `タオル` のような曖昧語は、
検索では候補商品をすべて表示します。

これは表示絞り込みだけなので、
parserの「曖昧なら完売反映しない」という安全ルールには影響しません。

## スマホから実際に見るには

UIはスマホ向けにしていますが、
現在PCで `streamlit run app.py` しているだけの場合、
外出先のスマホからアクセスできる状態にはまだなっていません。

最終段階でStreamlit Community Cloud等へデプロイするか、
自前サーバーへ配置する工程が別途必要です。
