# Phase 8.1 — 公演日付とDay表記が矛盾した場合の優先順位

公演判定の優先順位を以下に変更しました。

```text
対象ツアー
↓
会場 / 都道府県
↓
Day1 / Day2 / 1日目 / 2日目
↓
日付
```

そのため、公式投稿に以下のような誤記があっても、

```text
8/29 福岡 Day2
```

福岡のDay2が一意に特定できる場合は、

```text
2026-08-30
FRESHEST_FUKUOKA_0830
```

として扱います。

## 安全条件

- 会場名または都道府県名は必須
- Day表記が存在する場合だけ日付より優先
- 指定されたDayがその地域に存在しなければ判定停止
- 地域なしの `Day2` だけでは判定しない
- Day表記がない投稿は従来どおり日付を使用

つまり、運営側の誤記を一般的に推測するのではなく、
「地域 + 明示されたDay番号」が一意なときだけ補正します。
